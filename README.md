## 🔥 Modules and main functionnalities

The acesymmetry package contains two modules.

```python
from acesymmetry import Format_Conversion

from acesymmetry import Visual_Display
```

*Format_Conversion* supports data conversions from molecule names or SMILES to xyz files generation.

*Visual_Display* gives functionnalities for reading xyz files and displaying the molecule with the set of symmetry elements it contains.

#### Examples:

For a quick generation of the SDF and xyz files of a specific molecule most stable conformer (computed) the following lines of code may be used:

```python
from acesymmetry import Format_Conversion as conv

# from a SMILES:
conv.overall_conversion_from_smiles("molecule_SMILES")

# from a IUPAC or common name:
conv.overall_conersion_from_name("molecule_name")
```

Nota: the current programm doesn't support the presence of metallic atoms in the molecules due to the need of heavy electronic computations in the conformer generation.

The number of evaluated conformers in the files generation may be selected by the user. It is by default set of 1000.

```python
conv.overall_conversion_from_name("mol", num_confs=conformer_number)
```

Keep in mind that the higher the number of conformer generated, the more accurate the results, but the longer the computation time.

The xyz file generated by the *Format_Conversion* module may be used to find the point group and set of symmetry elements of the molecule:

```python
from acesymmetry import Visual_Display as vd

# to quickly get the symmetry elements' labels
vd.get_labels(xyz_file_name)
``` 

Some other of the major functions of this second module are: 

```python
vd.read_xyz_file(xyz_file_name) # Correspondance between the generated xyz file and the pointgroup package

vd.get_barycentre(xyz_file_name) # To compute the center of mass of the molecule and save it in an xyz file

vd.display(xyz_file_name) # To generate a .png representation of the molecule from the xyz file by using the xyzrender package
``` 

The get_barycentre() function fall within the intention of building a broader tool that would display the symmetry elements of molecule onto its representation. However, due to time constraints this will be part of further developments and is not included in the first version of the acesymmetry package.


## ACEsymmetry application

The package also contains an application which is its main feature as it uses all the coded functionnalities to give an interactive experience of molecular symmetry exploration.

The application may be started by using the following command in the terminal:

```
acesymmetry_app
```

This convient way of launching the application requires typer, but works from wherever on your computer.

Once the application launched, a new window will open in your browser. Note that because of the use of the pubchempy library, an internet connection is needed for a proper run of the whole script.

<p align="center">
    <img src=https://github.com/csalardi/ACEsymmetry/blob/main/assets/Homepage.png>
</p>

The first thing you will see is the homepage, where you can either select *Point Group* for the determination of the symmetry elements of a molecule by the programm, or *Learning mode* to train yourself in point group determination by following a decisional chart.

<p align="left">
    <img src=https://github.com/csalardi/ACEsymmetry/blob/main/assets/Input.png width="400" height="300">
</p>

In *Point Group* several input formats are supported. (Name, SMILES, Drawing) Make your choice !

<p align="center">
    <img src=https://github.com/csalardi/ACEsymmetry/blob/main/assets/Conformer.png>
</p>

You can choose the number of conformer that will be generated in the computation. This is linked to both the result accuracy and calculation time !

<p align="left">
    <img src=https://github.com/csalardi/ACEsymmetry/blob/main/assets/File_names.png width="400" height="300">
</p>

You can fully choose how to name the generated files. You can also choose the keep the default settings of naming the files with the IUPAC name of the molecule.

Note that the files will generate in the folder were you launched the application.

<p align="center">
    <img src=https://github.com/csalardi/ACEsymmetry/blob/main/assets/Output.png>
</p>

The output displays a visual representation of the molecule as well as its point group and the symmetry elements it contains.

To close the application, it is necessary to both close the window of your browser and cancel the launch command in the interface with *ctrl + C*.


## 👩‍💻 Installation of the package

To explore molecular symmetry, start by creating a new environment containing the ACEsymmetry package and its dependencies. (You may give the environment a name of your choosing.)

```
conda create -n ace_symmetry python=3.10 
```

```
conda activate ace_symmetry
(ace_symmetry) $ pip install git+https://github.com/csalardi/ACEsymmetry.git
```


## 🛠️ Development installation

To install the package while being able to edit the code, you can install it with the -e flag. To do so, a local clone of the repository need to be created: 
```
$ git clone https://github.com/csalardi/ACEsymmetry.git
```
```
conda create -n ace_symmetry python=3.10
conda activate ace_symmetry
```
Once in the folder corresponding to the repository run the pip install command:
```
(ace_symmetry) $ cd ACEsymmetry
(ace_symmetry) $ pip install -e .
```


## Key dependencies

The following dependencies are essential for the functionning of the acesymmetry package. They should all be automatically installed when downloading the present package. However, it is recommended to check their installation by using the command:

```
(ace_symmetry) $ conda list | grep <package_name>
```

- [**rdkit**](https://www.rdkit.org/)  
- [**streamlit**](https://streamlit.io/)  
- [**streamlit_ketcher**](https://github.com/streamlit/streamlit-ketcher)  
- [**pointgroup**](https://github.com/abelcarreras/pointgroup)  
- [**numpy**](https://numpy.org/)  
- [**pubchempy**](https://docs.pubchempy.org/en/latest/)  
- [**xyzrender**](https://github.com/aligfellow/xyzrender)  
- [**typer**](https://typer.tiangolo.com/) 

If one dependencie is missing you can install it with the command:

```
(ace_symmetry) $ pip install <missing_package>
```

Amoung the dependencies of this package is typer. This enables you to launch the ACEsymmetry application from wherever on your computer as long as the ace_symmetry environment is activated. With typer, you only need to enter acesymmetry_app in your terminal and it will automatically launch the application.


## Optional dependencies

- [**tox**](https://python-basics-tutorial.readthedocs.io/en/latest/test/tox.html)  

Tox is on optional dependency for automatic testing of the package. It is not required for the present package to be running.
